# Suspicious Activity

This directory contains controlled lab detections that do not belong to a single protocol or attack category.

Each detection should include:

1. What activity was generated
2. What telemetry source recorded it
3. The SPL query
4. Expected and observed results
5. Investigation notes
6. False-positive considerations
7. Tuning changes
8. Evidence
9. Limitations

Do not label a behavior as detected until the telemetry and detection have been validated.
