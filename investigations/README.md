# Investigations

This directory contains analyst-style investigations performed against events generated in the lab.

## Investigation Workflow

1. Identify the suspicious event.
2. Establish the timeline.
3. Identify source and destination systems.
4. Review related telemetry.
5. Determine what activity occurred.
6. Decide whether the activity is expected, suspicious, or inconclusive.
7. Record supporting evidence.
8. Document the next action.

Use timestamps and event fields as evidence rather than assumptions.
